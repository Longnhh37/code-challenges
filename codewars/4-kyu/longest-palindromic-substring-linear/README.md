<h2><a href=https://www.codewars.com/kata/5dcde0b9fcb0d100349cb5c0/train/rust target="_blank">Longest Palindromic Substring (Linear)</a></h2><h3>4 kyu</h3><h1 id="longest-palindromic-substring-linear">Longest Palindromic Substring (Linear)</h1><p>A palindrome is a word, phrase, or sequence that reads the same backward as forward, e.g.,'madam' or 'racecar'. Even the letter 'x' is considered a palindrome. </p><p>For this Kata, you are given a string <code>s</code>. Write a function that returns the longest <em>contiguous</em> palindromic substring in <code>s</code> (it could be the entire string). In the event that there are multiple longest palindromic substrings, return the first to occur.</p><p>I'm not trying to trick you here:</p><ul><li>You can assume that all inputs are valid strings.</li><li>Only the letters a-z will be used, all lowercase (your solution should, in theory, extend to more than just the letters a-z though).</li></ul><p><strong>NOTE:</strong> Quadratic asymptotic complexity <em>(O(N^2))</em> or above will <strong>NOT</strong> work here.</p><hr><h2 id="examples">Examples</h2><h3 id="basic-tests">Basic Tests</h3><pre><code>Input: "babad"Output: "bab"(Note: "bab" occurs before "aba")</code></pre><pre><code>Input: "abababa"Output: "abababa"</code></pre><pre><code>Input: "cbbd"Output: "bb"</code></pre><h3 id="edge-cases">Edge Cases</h3><pre><code>Input: "ab"Output: "a"</code></pre><pre><code>Input: ""Output: ""</code></pre><hr><h2 id="testing">Testing</h2><p>Along with the example tests given:</p><ul><li>There are <strong>500</strong> tests using strings of length in range [1 - 1,000]</li><li>There are <strong>50</strong> tests using strings of length in range [1,000 - 10,000]</li><li>There are <strong>5</strong> tests using strings of length in range [10,000 - 100,000]</li></ul><p>All test cases can be passed within 10 seconds, but non-linear solutions will time out every time. <em>Linear performance is essential</em>. </p><h2 id="good-luck">Good Luck!</h2><hr><p>This problem was inspired by <a href="https://leetcode.com/problems/longest-palindromic-substring/" data-turbolinks="false" target="_blank">this</a> challenge on LeetCode.
