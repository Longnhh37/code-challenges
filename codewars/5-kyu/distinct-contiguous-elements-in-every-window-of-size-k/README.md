Answer: [3,4,4,3]</code></pre><h2 id="explanation">Explanation</h2><pre><code>1st window is `{1, 2, 1, 3}`, which has `3` distinct numbers2nd window is `{2, 1, 3, 4}`, which has `4` distinct numbers3rd window is `{1, 3, 4, 2}`, which has `4` distinct numbers4th window is `{3, 4, 2, 3}`, which has `3` distinct numbers</code></pre><h2 id="warning">WARNING</h2><p>Be careful about performance: your function will have to manage <code>150</code> random tests with arrays of length between <code>10 000</code> and <code>20 000</code> and size of the window between <code>1 000</code> and <code>10 000</code> !</p>
