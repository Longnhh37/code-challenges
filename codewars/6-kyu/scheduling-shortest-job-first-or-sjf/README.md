<h2><a href=https://www.codewars.com/kata/550cc572b9e7b563be00054f/train/rust target="_blank">Scheduling (Shortest Job First or SJF)</a></h2><h3>6 kyu</h3><p>Scheduling is how the processor decides which jobs (processes) get to use the processor and for how long. This can cause a lot of problems. Like a really long process taking the entire CPU and freezing all the other processes. One solution is Shortest Job First (SJF), which today you will be implementing.</p><p>SJF works by, well, letting the shortest jobs take the CPU first. If the jobs are the same size then it is First In First Out (FIFO). The idea is that the shorter jobs will finish quicker, so theoretically jobs won't get frozen because of large jobs. (In practice they're frozen because of small jobs).</p><p>You will be implementing a function that takes in:</p><ol><li>"jobs", a non-empty array of positive integers. They represent the clock-cycles(cc) needed to finish the job.</li><li>"index", a positive integer. That represents the job we're interested in.</li></ol><p>SJF returns:</p><ol><li>A positive integer representing the cc it takes to complete the job at index.</li></ol><p>Here's an example:</p><pre><code>jobs: [3, 10, 20, 1, 2]index: 0at 0cc [3, 10, 20, 1, 2] jobs[3] startsat 1cc [3, 10, 20, 0, 2] jobs[3] finishes, jobs[4] startsat 3cc [3, 10, 20, 0, 0] jobs[4] finishes, jobs[0] startsat 6cc [0, 10, 20, 0, 0] jobs[0] finishesShould return 6, as it takes 6cc to complete the job at index 0</code></pre>
